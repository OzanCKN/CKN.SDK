# Examples (Kullanım Örnekleri) İndeksi

## 📌 Amaç
Bu dizin, SDK içerisindeki tüm modüllerin son geliştiriciler tarafından nasıl kullanılacağını (appsettings yapılandırmaları, DI register, kod örnekleri) göstermek amacıyla oluşturulmuştur.

## 📂 İçerik
- [📄 ai-examples.md](./ai-examples.md) - OpenAI, Anthropic, Ollama ve Semantic Kernel kullanım örnekleri.
- [📄 caching-examples.md](./caching-examples.md) - Redis, Memcached ve Garnet kullanım örnekleri.
- [📄 data-access-examples.md](./data-access-examples.md) - Dapper, RepoDb (Bulk) kullanım örnekleri.
- [📄 messaging-examples.md](./messaging-examples.md) - Kafka, RabbitMQ, ServiceBus kullanım örnekleri.
- [📄 scheduling-examples.md](./scheduling-examples.md) - Hangfire, Quartz ve Coravel kullanım örnekleri.
- [📄 search-examples.md](./search-examples.md) - Elasticsearch, Meilisearch ve NRedisStack kullanım örnekleri.
- [📄 storage-examples.md](./storage-examples.md) - Minio, AWS S3 ve Azure Blob kullanım örnekleri.

## 📝 Diğer Bilgiler (Şablon Dışı Notlar)
Eklenen tüm örneklerin gerçek dünya (real-world) senaryolarına dayanması ve yalnızca teorik `Foo/Bar` isimlendirmelerinden kaçınılması zorunludur (Örneğin `InvoiceJob`, `ProcessOrder` gibi somut isimlendirmeler yapılmalıdır).
