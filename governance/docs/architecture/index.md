# Architecture (Mimari) İndeksi

## 📌 Amaç
Bu dizin, sistemin temel kurallarını, Zero-Warning Policy gibi katı yönergeleri ve tüm sistem bileşenlerinin görevlerini bir sözlük mantığında açıklamak için oluşturulmuştur.

## 📂 İçerik
- [📄 standards.md](./standards.md) - Temel mimari standartlar, CKN.SDK kural setleri ve Clean Code yönergeleri.
- [📄 system-glossary.md](./system-glossary.md) - MANDATORY READ (Zorunlu Okuma) belgesidir. Projedeki tüm SDK modüllerinin ve arayüzlerinin haritası.

## 📝 Diğer Bilgiler (Şablon Dışı Notlar)
Sisteme yeni bir SDK modülü veya arayüz eklendiğinde `system-glossary.md` kesinlikle güncellenmelidir. Herhangi bir AI ajanı projede çalışmaya başlamadan önce bu sözlüğü hafızasına almalıdır.
